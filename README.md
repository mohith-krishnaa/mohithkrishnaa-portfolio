## 🚀 Running Locally

The portfolio is engineered as an ultra-fast, zero-dependency static web application:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/mohith-krishnaa/mohithkrishnaa-portfolio.git
   cd mohithkrishnaa-portfolio
   ```

2. Open `index.html` directly in any modern browser, or run a local web server:
   ```bash
   # Python HTTP server
   python -m http.server 3000
   ```
3. Open `http://localhost:3000` in your browser.
